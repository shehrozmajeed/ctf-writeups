## 🛠️ Repository Summary

These notes are structured directly from my hands-on practice. They represent a deep-dive into:

*   **Reconnaissance & Scanning**: Master scanning targets using tools like `Nmap` and parsing outputs.
*   **Web Vulnerabilities**: Dive deep into OWASP Top 10 vulnerabilities (XSS, CSRF, Injection, File Inclusion).
*   **Burp Suite**: Use the proxy, repeater, and intruder modules for intercepting and analyzing traffic.
*   **Scripting**: Automate security checks and tasks using Python.
*   **Defensive Security**: Understand the role of SOC, cyber kill chain models, and humans/systems as attack vectors.
