# 🛡️ Jr Penetration Tester Notes

This section contains learning notes, key concepts, commands, and methodologies from the **Jr Penetration Tester** path.

## 📚 Modules Covered

Here is the list of topics and chapters covered:

*   **01-Start Your Cyber Security Journey**: Getting started, offensive vs defensive security.
*   **02-Penetration testing foundations**: Cyber kill chain, pentesting frameworks, and guided pentest notes.
*   **03-Network Reconnaissance**: Protocols, active and passive reconnaissance methods.
*   **04-nmap**: Live host discovery, basic port scans, advanced port scans, and post-scan techniques.
*   **05-Web Application Security Fundamentals**: Content discovery, walking an application, modern web stacks, and web server attacks.
*   **06-Burp Suite**: Detailed notes on using Burp Proxy, Repeater, and Intruder.
*   **07-Web Applications Vulnerabilities 1**: SQL Injection, CSRF, XSS, and SSRF.
*   **08-Web Applications Vulnerabilities 2**: Command Injection, Session Management, API Pentesting, and File Inclusion.
*   **09-Vulnerability Knowledge**: Databases, scanning tools, basic identification, and specific CVE studies.
*   **10-OWASP TOP 10 (2025)**: Understanding identity failures, insecure data handling, and design flaws.
*   **12-Metasploit and Exploitation**: Basics of Metasploit and running exploits.
*   **16-python Scripting Basics**: Python concepts, building scripts, and writing pentesting tools.
*   **17-Pentesting Methodologies and Reporting**: Threat modeling, planning, scoping, reporting, and re-testing.
